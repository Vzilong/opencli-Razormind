1. 运行时不再只是安装检测：Codex JSONL、OMP 上游 SDK/RPC 接入现有持久会话；服务端将工作区、运行时、唯一节点、工作目录与超时绑定并保存映射指纹。

   专用节点同时在统一派发入口隔离，通用 Operations Agent/Workbench 不能借用该账号；任务 JSON 不能伪造内部授权标记。

6. 原生节点不可用时提供“重试执行配置”，节点重连后原草稿可继续发送；原生账号执行不再要求额外配置 OpenCLI Provider。

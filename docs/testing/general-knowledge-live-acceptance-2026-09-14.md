# 通用知识库阶段验收

日期：2026-09-14。范围对应 Issue #134、ADR-0047 的首个实施阶段。

## 已交付

- 工作区知识库不依赖品牌；支持原始资料、编辑、发布、搜索、问答入口、版本与下载。
- 项目通过显式知识库绑定获得下游查询权限；解绑不从旧品牌分类恢复授权。
- 兼容迁移保留旧资料 ID、字节、哈希、修订和产品限定范围。可能丢失通用数据或改变授权的降级会拒绝执行。
- 默认导航移除品牌入口；数据页按工作区与项目筛选，不进行无范围加载，并移除全局清空按钮。旧品牌链接和产品过滤仍兼容。

## 新鲜验证

- 集成分支运行知识库、旧品牌知识、迁移、迁移头、agent-data service、REST、MCP 共 49 项后端测试，全部通过。
- 通用知识库及首发体验 Playwright 共 15 项通过（27.6 秒）；TypeScript `tsc --noEmit` 成功。
- 独立审查另行通过 27 项库/迁移/兼容测试；SQLite 降级实验确认保留字节和版本、已撤销授权不恢复。该数量与上述后端测试有重叠，不相加。
- 真实隔离数据库迁移前使用 SQLite backup 保存副本，完整性检查为 ok；随后服务正常启动并应用迁移。

## 边界

没有执行真实 PostgreSQL 迁移。本轮上传的是验收资料，REST/MCP 验证证明授权检索，不代表真实模型推理或完整研究报告链路已通过。独立 Dataset 实体、成果导航拆分及三个模板的全部端到端链路仍需后续验收。

## 协作与返工

后端迁移采用 Terra High 独立 worktree，界面由另一 worktree 负责，主 Agent 负责下游授权整合和真实验收，独立审查负责迁移与权限。审查期间修正可选说明的空值、未保存编辑的切换保护和全局清空入口；截图检查另修正遗留品牌文案。没有扩大授权范围以绕过兼容问题。
